# Voxlace design system (MASTER)

Global source of truth, in the ui-ux-pro-max Master + Overrides layout. **Extracted from the
shipped code and locked (21 Nov 2026)**: nothing here was generated by a tool, and a tool's
suggestion never replaces it. The tokens live in `frontend/src/index.css`, the component
recipes in `frontend/src/lib/ui.ts`, the reasoning in `docs/DESIGN.md` §5–§7. Page rules that
differ go in `pages/<page>.md` and win over this file for that page.

### Pattern

A calm writing tool. The user's words are the loudest thing on screen; the interface recedes.
One primary action per screen. Everything optional sits behind progressive disclosure and
never blocks the main flow. Structure borrowed from ChatGPT, Claude and Canvas (composer,
side panel, streaming, starters), never their look.

### Style

Flat, neutral, light and dark. Borders separate, shadows only float (composer, menus,
dialogs, toasts). One card level: never a bordered card inside a bordered card. Teal is the
AI's mark only. No gradients, no decoration without a job.

### Typography

Inter 400 and 600 only (Noto Sans Ethiopic for Amharic); JetBrains Mono for keys and code.
Sizes 13 / 14 / 16 / 18 / 22 / 30px (`text-xs` … `text-2xl`). Writing line-height 1.65,
interface 1.5. Sentence case everywhere. Counters use tabular numbers.

### Shape and space

4px grid. Radius: 10px controls, 16px panels, 28px composer, pills for buttons and chips.
Controls are 40px with a mouse and **44px on touch** (global rule in index.css).

### Components (`lib/ui.ts`)

| Recipe | Use |
|---|---|
| `primary` | The one main action on a screen |
| `secondary` | Other actions (outlined pill) |
| `ghost` | Low emphasis, text only |
| `iconButton` | Icon-only; needs `aria-label` and a `Tooltip` |
| `chip` / `chipOn` | Platforms, quick changes, starters |
| `field` | Inputs and selects |
| `panel` | A bordered card |
| `Tooltip`, `Kbd` (`components/ui/tooltip.tsx`) | Icon labels and shortcut hints; never `title` |

### Key Effects

- Focus: 2px `--thread` ring on every control (`:focus-visible`).
- Hover: the `--sunken` tint; primary dims to 90%.
- A new draft's text fades up once (`.animate-reveal`).

### Motion

`--duration` 150ms (hover, color), `--duration-reveal` 200ms (something appearing),
`--ease` cubic-bezier(0.2, 0, 0, 1). Transform and opacity only. `prefers-reduced-motion`
sets every duration to 0.

### Avoid (Anti-patterns)

- Developer words for everyone ("RAG", "embedding", "tokens", "commits") outside Connections.
- More than one filled primary button in view.
- Native `title` tooltips; icon buttons without a label.
- Spinners with no words; waits with no end; raw errors or status codes.
- Gates: nothing optional may block writing a draft.
- New colors, fonts or radii outside the tokens; shadows on in-flow elements.

### Pre-Delivery Checklist

- [ ] 360 / 768 / 1440 in light and dark, no sideways scroll
- [ ] One primary action per screen
- [ ] Touch targets 44px; focus visible; every input labelled
- [ ] Every AI state designed: empty, waiting, slow, error, limit, unavailable, done
- [ ] Copy: plain, short, sentence case, says what happens and how to fix
- [ ] Reduced motion respected
