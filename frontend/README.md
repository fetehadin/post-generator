# Frontend

React + Vite + TypeScript app. Scaffolded in **Phase 0** with `npm create vite@latest . -- --template react-ts` — see [`docs/BUILD_PLAN.md`](../docs/BUILD_PLAN.md#phase-0--foundations).

Screens, in build order: Upload → Generate → Login → Onboarding → Settings → Chat board → Draft editor → Library → Calendar.

Build each screen against fake data that matches [`docs/API.md`](../docs/API.md) first, then switch to the real API.

Working rules for humans and Claude: [`CLAUDE.md`](CLAUDE.md).
